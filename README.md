# Style Changer - Chrome 拡張機能

> ページのフォントスタイルを自由に変更できる Chrome 拡張機能

## 📖 概要

Style Changer は、Web ページのフォントファミリー、サイズ、ウェイトを簡単に変更できる Chrome 拡張機能です。手描き風の温かみのある UI デザインで、直感的に操作できます。

## ✨ 機能

- **フォントファミリー変更**: 明朝体、ゴシック体、等幅フォントなど選択可能
- **カスタムフォント対応**: PC にインストール済みのフォントを直接指定
- **フォントサイズ調整**: 10px〜36px まで自由に設定
- **フォントウェイト変更**: 細字から太字まで 8 段階
- **ON/OFF スイッチ**: ワンクリックでスタイル適用の切り替え
- **設定の永続化**: ブラウザを閉じても設定を保持
- **リアルタイム反映**: 設定変更が即座にページに適用

## 🎨 デザイン

手描き風のスタイルを採用した温かみのある UI：

- ベース背景: #F5F0E8 (クリーム色)
- セクション背景: #A2865C (アースブラウン)
- メインテキスト: #1A1A4B (ネイビーブルー)
- アクセント 1: #FF8C42 (ソフトオレンジ)
- アクセント 2: #E03E36 (ウォームレッド)

## 🚀 インストール方法

### 1. 拡張機能の準備

```bash
git clone <このリポジトリのURL>
cd change-favorite-style
```

### 2. アイコンファイルの生成

1. `convert-icons.html` をブラウザで開く
2. 各サイズのアイコンをダウンロード：
   - icon16.png (16×16px)
   - icon32.png (32×32px)
   - icon48.png (48×48px)
   - icon128.png (128×128px)
3. ダウンロードした PNG ファイルをプロジェクトフォルダに配置

### 3. Chrome に拡張機能をインストール

1. Chrome で `chrome://extensions/` を開く
2. 右上の「デベロッパーモード」を ON にする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. このプロジェクトフォルダを選択

## 📱 使い方

### 基本操作

1. **拡張機能アイコンをクリック**してポップアップを開く
2. **「スタイル適用」スイッチ**を ON にする
3. お好みの設定を調整：
   - フォント選択
   - サイズ調整（スライダー）
   - 太さ選択

### カスタムフォントの使用

1. フォント選択で**「カスタム」**を選択
2. 入力欄にフォント名を入力
   - 例: `"Yu Gothic"`, `"Meiryo"`, `"Arial"`
   - 複数指定も可能: `"Noto Sans JP", sans-serif`

### 設定例

```
フォント: カスタム → "Yu Gothic UI"
サイズ: 18px
太さ: 500
```

## 🛠️ 技術仕様

- **Manifest Version**: 3
- **対応ブラウザ**: Chrome, Chromium 系ブラウザ
- **必要な権限**:
  - `storage`: 設定の保存
  - `activeTab`: アクティブタブへのアクセス
  - `<all_urls>`: 全サイトでの動作

### 主要技術

- HTML5 + CSS3
- Vanilla JavaScript (ES6+)
- Chrome Extension APIs
- SVG + Canvas (アイコン生成)

## 🔧 開発

### コードスタイル

- const 定義を優先使用
- アロー関数を標準採用
- 非同期処理は async/await

### カスタマイズ

- カラーパレットは `popup.css` で一元管理
- フォント選択肢は `popup.html` で追加可能
- スタイル適用ロジックは `content.js` で調整
